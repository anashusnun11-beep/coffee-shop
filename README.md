# Ember & Bean — Coffee Shop Landing Page

A responsive, dependency-free landing page for a neighborhood coffee shop.

## Sections
- **Hero** with an animated SVG coffee cup, call-to-action buttons and quick stats
- **Features** — roasting, direct trade, bakery
- **Menu** with accessible tabs (Espresso / Slow Bar / Bakery)
- **Our Story**, **Reviews**, and **Visit** (address, hours, live open/closed status)
- **Newsletter signup** (front-end demo, no backend)

## Run it
No build step. Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 8000
```

## Files
- `index.html` — markup
- `styles.css` — styles (CSS variables at the top for easy re-theming)
- `script.js` — mobile nav, menu tabs, open-hours badge, scroll reveal, signup demo
